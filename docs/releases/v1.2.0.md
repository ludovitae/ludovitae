# v1.2.0 — Real spending & model honesty (2026-07-11)

Tag: `v1.2.0`. First release tagged live under the release protocol.

## Features

- **Credit cards without double-entry pain**: spending counts at the swipe;
  checking→card payments auto-pair as transfers (exact amount, opposite
  sign, ±4 days) and vanish from all analytics; interest/fees are real
  spending. Unpairs and dismissals tombstone — they survive re-imports.
- **Layered categorization**: manual > your rules (payee patterns, priority
  ordered, retroactive apply) > built-in heuristics. AI categorization is
  stubbed; the **AI budget admin** ships first: write-only API key storage,
  monthly budget with hard-stop enforcement, token/spend ledger.
- **Import freshness**: per-account fresh/aging/stale badges (35-day default,
  per-account override), dashboard warning strip. Badges obey the new
  attention-economics rules: cap at 9+, clear when handled, one surface per
  concern.
- **Spending hub** (tabs: Plan / Summary / Recurring / Hotspots / Forecast):
  category×month heatmap; **subscription radar** segmenting true
  subscriptions from spending habits via amount variability, with
  price-increase badges and a "possibly forgotten" group (≤$100/mo,
  low-variance, running ≥12 months); category spikes vs your own baseline;
  recurring+variable forecast with annual charges lumped in their
  anniversary months.
- **Review queues** (`/review`): transfer candidates side-by-side with
  persistent pair/dismiss; uncategorized transactions with bulk categorize
  and create-rule-from-payee.

## Model honesty (engine v2)

- Taxable Social Security is now capped at 85% (was implicitly 100%) — the
  engine was overstating retirement taxes. Golden household movement:
  success probability 0.737 → 0.742; median ending net worth $2.52M → $2.58M;
  deterministic ending net worth $4.24M → $4.34M.
- Every simulation response now carries an `assumptions` block (market
  means/vols, inflation, tax knob, SS taxable share) and `engine_notes`
  describing behavior changes. Cached results are keyed by engine version.

## Also in this release

  engine integration is the next phase; unblocks RSU withholding-gap,

## Quality

279 server / 136 web tests at ship (v1.1.0: 162/97). End-to-end verified:
seeded household auto-pairs 14/14 card payments (empty candidate queue),
flags the Netflix 16.1% hike, finds 3 forgotten subscriptions, reports the
stale savings account, and simulates with engine-v2 assumptions attached.
