# v1.1.0 — Household & retirement timing (2026-07-11)

Tag: `v1.1.0` at `f108e5d` (retro-tagged 2026-07-11 when release tagging was
adopted).

The simulator learns who is in your life and when retirement events happen.

## Features

- **Household members**: people with roles (self/partner/child/other), birth
  years, life expectancies; accounts and income flows can be owned, so each
  person's salary stops at *their* retirement. Exactly-one-self invariant;
  simulation horizon = oldest adult's life expectancy (children never extend
  it).
- **Retirement timing**: per-member Social Security claim age (62–70) with
  real actuarial factors (62→70% … 70→124% of FRA benefit); RMDs per SECURE
  2.0 (start 73/75 by birth year) using the IRS Uniform Lifetime Table
  against per-member tax-deferred buckets.
- **Milestones on the fan chart**: the engine emits retirement / SS-claim /
  RMD-start events per member under each scenario's overrides; the chart
  renders them as labeled, collision-staggered, CVD-validated markers that
  move live with the timing sliders.
- **Scenario member overrides**: per-member retirement-age and claim-age
  sliders (live benefit-factor readout) + household spending-delta.
- **Spending profile**: essential/discretionary categories, savings target,
  and observed-spending calibration computed from imported transactions
  ("use observed" per category).

## Migration safety

Existing v1 databases upgrade in place; a recorded-golden test proves a
migrated single-adult household simulates **bit-for-bit identically** to v1.
