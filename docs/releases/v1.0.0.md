# v1.0.0 — Foundations (2026-07-10)

Tag: `v1.0.0` at `b824ef0` (retro-tagged 2026-07-11 when release tagging was
adopted).

First working release: a self-hosted financial life simulator on your LAN.

## Features

- **Auth & serving**: single-password login (argon2id), server-side sessions,
  CSRF protection, login throttling, security headers, self-signed TLS via
  `gol-serve`; FastAPI serves the built UI and API from one process.
- **Money model**: accounts across 12 types (incl. property/vehicles/debts)
  with balance-snapshot history; recurring flows (income/expense/
  contribution); goals.
- **Simulation**: deterministic projection + vectorized Monte Carlo
  (percentile fan, success probability, ruin age), scenario studio with
  what-if params and one-time/recurring events, scenario compare.
- **Import**: CSV (column mapping) + OFX with dedupe; 5 MB cap, fail-closed
  parsing.
- **UI**: dark-first `fintech` theme + `game` token-skin behind a settings
  flag; hand-rolled SVG fan/area charts with tweened transitions; designed
  empty states; keyboard navigable.
