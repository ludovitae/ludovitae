# v1.2.1 — Durability, honesty UI & the move to GitHub (2026-07-11)

Tag: `v1.2.1`. First release cut through the PR workflow (owner-merged) and
the first with a PyPI publish pipeline.

## Features

- **Backups & export (T-010 / PR #1)**: automatic pre-migration backup before
  any schema change touches a non-empty database (keep 5); daily consistent
  snapshots while the server runs (keep 14); `GET /export` downloads the
  entire database as one JSON document — the AI API key is never included.
  Restore is a documented file operation (README "Backups & restore").
- **Model-honesty UI (T-011b / PR #3)**: an assumptions strip under the fan
  chart states what the model assumed (from the actual run, scenario
  overrides included) and its known limits; success probability now displays
  to the nearest 5% ("~75%", exact value in tooltips); engine-version changes
  surface their notes once, dismissably.
- **Project identity (PR #2 + direct)**: Ludovitae (MIT licensed), GitHub org
  `ludovitae`, CI on every PR, PyPI Trusted Publishing workflow —
  distribution renamed `gol` → `ludovitae` (import package unchanged,
  rename tracked separately).
- **Process**: main requires PRs (owner merges); the work board moved to
  GitHub issues (#4–#8).

## Quality

291 server / 148 web tests at ship (v1.2.0: 279/136). No engine behavior
changes in this release (engine stays v2; no golden movement).

## Known gaps

`pip install ludovitae` ships the server only — the built web UI is not yet
bundled into the wheel. First-real-baseline (issue #4) and bracket-tax
integration (issue #5) are the next feature work.
